# pubmed-dvi-rss

Flux RSS quotidien des publications PubMed sur le DVI / imagerie forensique.

- Régénéré chaque jour 06:17 UTC par GitHub Action (E-utilities, clé NCBI en secret)
- Sortie : `feed.xml` (30 items, titres + abstracts)
- Consommateur : Utopia (source RSS, sync 6 h) → base « DVI Forensic Corpus »

Flux brut : https://raw.githubusercontent.com/fabded2-ui/pubmed-dvi-rss/main/feed.xml
